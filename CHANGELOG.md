# Changelog

All notable changes to this project are documented in this file.

The format follows a simple version-based structure for clarity and traceability.

---

## [v2.0] – Major Visual & Structural Upgrade
**Release date:** 2026-01-08

### Added
- Full continent pages with dedicated background images
- Three structured sections for each continent:
  - Explore
  - Highlights
  - Countries
- Glass-card style description panels
- Clickable country pages with individual information
- Swipeable Highlights section for mobile devices
- New visual assets and icons
- GitHub Pages deployment updates

### Changed
- Typography improved for smoother reading (spacing, sizing, contrast)
- Background overlays adjusted to improve text readability on images
- Navigation structure expanded for better flow
- Layout refined for consistency across all continents
- Mobile viewport handling improved to avoid browser UI overlap

### Improved
- CSS animations and transitions for a more dynamic, “alive” experience
- Overall visual polish and user experience
- Responsiveness across screen sizes and devices

---

## [v1.0] – Initial Release
**Release date:** 2025-12-22

### Added
- Initial homepage with welcome text
- Basic continent navigation
- Static continent and country display
- Core HTML and CSS layout structure
- Responsive layout foundation using Flexbox

### Limitations
- No background images
- No continent-specific pages
- Countries were not clickable
- Country flags displayed immediately without interaction
- Minimal styling and animations

---

## Notes
- v1.0 served as a foundational learning version
- v2.0 represents a full design and experience upgrade
